# Sketché privacy policy

The public privacy policy for the Sketché Android app (`works.foundy.sketche`) by
Foundy Works, served by GitHub Pages at <https://dewabuanam.github.io/sketche-policy/>.
This is the URL given to Google Play.

`index.html` is self-contained: no scripts, no external fonts or requests. The same text
is the policy page of the Sketché website; change both together.
